# Comment Style JA

コードだけでは読み取れない意図や前提を、日本語で短く補う。
Docstringを変更する場合は`python-docstring-ja`に従う。

## 残す内容

- 外部HTMLやCLIなど、コードの外にある仕様や制約。
- 重複判定、停止条件、順序保証、例外処理の判断理由。
- テストの差し替えやhelperなど、名前だけでは分かりにくい役割。

## 省く内容

- 処理の読み上げや、条件式を日本語にしただけの説明。
- テスト名、Docstring、変数名で十分に分かる内容。
- 件数、fixture内容、細かい実装名など、変更時に古くなりやすい説明。

同じ説明の繰り返しは減らすが、学習・レビュー目的で必要なら短く残してよい。
抽象的な語は具体化し、文として自然なら句点を付けてよい。
