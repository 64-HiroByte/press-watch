# PressWatch Markdown Style JA

## 基本方針

- 日本語の本文は、原則として一文を一つの物理行に置く
- 文の途中で、表示幅やソース上の折り返しだけを理由に改行しない
- 同じ段落に複数の文を置く場合も、文ごとに改行する
- 段落を分ける場合だけ空行を入れる
- 見出しや短いラベルには、一文一行の形式を無理に当てはめない

## 箇条書き

- 一つの項目に複数の文を書く場合は、二文目以降を同じ項目の継続行に置く
- 継続行は、箇条書きの本文位置に揃えてインデントする
- 入れ子の箇条書きやコードブロックなど、既存の Markdown 構造を崩さない

```markdown
- 一文目を書く。
  二文目は同じ項目の継続行に置く。
```

## 例外

- コードブロックと表は、一文一行の対象外とする
- コマンド、JSON、YAML などの構造を持つ内容は、適切なコードブロックに置く
- 外部からの引用や自動生成された内容は、原文や構造を壊さないことを優先する

## 編集時の確認

- 今回変更する文章へ適用し、無関係な既存箇所を一括整形しない
- 一文一行への変更で、見出し、箇条書き、リンク、コードブロック、表の意味が変わっていないか確認する
- 変更後に `git diff --check` を実行する
- 文書の保存先や内容の責務は、対象に応じた既存スキルへ従う
