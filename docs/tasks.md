# PressWatch - Tasks

## 方針

- 1タスク = 1責務を意識し、レビューしやすい粒度に分ける。
- MVP完成を優先し、土台 → データ取得 → 保存 → API → 画面の順で進める。
- Codexには小さな単位で依頼し、差分ベースでレビューする。
- 作業ごとに対象・除外事項を明確にし、不要なリファクタリングを避ける。

作業範囲・承認・Git操作などの基本ルールは[リポジトリ指示](../AGENTS.md)に従う。
この文書ではタスクと進捗を管理し、チェック済みは必要な検証とレビューを終えた作業を表す。
仕様・手順・検証記録は関連Docsに置く。
